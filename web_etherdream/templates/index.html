⚡ Ether Dream Interactive Controller ⚡

Points: 0 Disconnected

Instructions:

  • Start the Docker container: docker run -it --rm -p 5901:5900 -p 7654:7654/udp -p 7765:7765/tcp openlase:gui etherdream_bridge
  • Open VNC viewer to localhost:5901 (password: openlase)
  • Click "Connect" to start streaming to the etherdream_bridge
  • Draw on the canvas with your mouse - hold and drag to draw
  • Your drawing appears in real-time in the VNC simulator
  • Choose different colors with the color picker
